# Changelog

All notable changes to the Obstacle-Avoiding Robot Car project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [1.0.0] — 2026-11-06

### Added
- Complete project reconstruction and documentation
- Arduino source code (`obstacle_avoiding_robot.ino`) with full obstacle avoidance logic
- HC-SR04 ultrasonic sensor integration with timeout handling
- L298N motor driver control for four DC motors
- Configurable speed, threshold, and timing parameters
- Alternating turn direction for improved obstacle navigation
- Serial monitor debugging output
- Comprehensive README with project overview and architecture
- Circuit documentation with wiring guide and pin configuration
- Hardware and software requirements documentation
- Working principle explanation with engineering concepts
- Installation guide for Arduino IDE setup
- Troubleshooting guide for common issues
- Testing plan with structured test cases
- Future improvements roadmap
- MIT License
- Contributing guidelines
- Appropriate `.gitignore` for Arduino projects

### Note
- This release is a reconstruction of the original first-year college project
- Original source code and documentation were not available
- All code and documentation have been recreated based on project requirements
- Hardware testing has NOT been completed — all tests are marked as NOT TESTED
- Placeholder spaces are provided for prototype photographs
