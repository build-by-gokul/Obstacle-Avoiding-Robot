## How to Add Images

1. Take clear, well-lit photographs of your robot and circuit
2. Name files descriptively (e.g., `front_view.jpg`, not `IMG_4521.jpg`)
3. Recommended resolution: at least 1920×1080 pixels
4. Supported formats: `.jpg`, `.png`, `.gif`
5. Update the main `README.md` to reference your images

## Referencing Images in Markdown

```markdown
![Description of image](images/your_image_name.jpg)
```
